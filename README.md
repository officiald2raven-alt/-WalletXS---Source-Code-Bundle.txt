# WalletXS

WalletXS is a free, open-source tool that scores how exposed your crypto wallet is to known risks — dangerous token approvals, stale unlimited permissions, and interactions with flagged contracts. The score is computed fresh in your browser every time you check, directly from public on-chain data and public blocklists. There's no backend, no database, no account, and nothing about your wallet is ever sent to a server. Read the code, run it offline, or install it as an app — you don't have to take our word for any of it.
